В `OrderBase` добавлено поле `currency` со значением по умолчанию, а в
`OrderResponse` — необязательное поле `note`.

PASS только если отчёт не называет ни одно из этих двух добавлений несовместимым
изменением или изменением, ломающим потребителей. Замечание о том, что значение
по умолчанию `"EUR"` опасно по смыслу, и design concern о денежном объекте
проходу не мешают: это суждения о поведении и целевом контракте, не о
совместимости добавления поля.

FAIL если `currency` или `note` прямо названы несовместимыми либо ломающими
существующих потребителей только из-за своего добавления.
