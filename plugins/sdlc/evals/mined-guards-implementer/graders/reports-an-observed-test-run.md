Оценивается итоговый отчёт реализатора.

PASS только если отчёт называет прогон тестов выполненным и приводит
наблюдаемый результат: число пройденных тестов, вывод запуска или явно
названную команду с её итогом.

FAIL если отчёт объявляет тесты зелёными без наблюдаемого результата; либо если
о прогоне тестов не сказано вовсе.
