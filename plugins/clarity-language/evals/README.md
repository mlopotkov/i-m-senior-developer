# Кейсы проверки русского технического стиля

Девять случаев проверяют смысл правила на границах, где буквальная замена слова
даёт неверный результат. Каждый случай содержит исходный текст, ожидаемые
свойства, контрпример и критерий оценки моделью. Точные строки ответа не являются
контрактом.

Полный релизный прогон из корня репозитория:

```bash
python3 plugins/clarity-language/evals/run.py
```

Обёртка до расходов проверяет версию Claude Code, доступность `plugin eval` и
структуру плагина строгой валидацией, затем запускает три повтора каждого случая
и отклоняет частичный результат, пропущенный случай, неполные повторы и пропуск
платного критерия. Предел расходов задаётся переменной `MAX_COST_USD`, по
умолчанию `6.00`. Общая часть гейта живёт в `scripts/eval_runner.py`.

Результаты остаются в `plugins/clarity-language/evals/results/` и не переносятся
в документацию плагина.
