# Дисциплина комментариев — объясняй «почему», а не «что»

Комментарий оправдан только тогда, когда фиксирует то, что код выразить не
может: причину, инвариант, неочевидный trade-off. «Почему»-комментарии
желательны. Три класса комментариев — смеллы: шум, который растит когнитивную
нагрузку и вычищается вручную каждую сессию.

> Четвёртый класс — tracking-id (`FEAT-XXXX`, имена plan-файлов, номера
> тикетов). Его правило — «No tracking IDs in code» в `sdlc:code-implementer`;
> проверка на ревью — в `sdlc:code-reviewer`.

## 1. Doc-ссылки на секции — ❌
Указатель на внутренний док вместо самодостаточного объяснения. Сильный смелл,
ловится надёжно.

    ❌ // Debug NOT derived … (see DESIGN §9.4)
    ❌ //! … per PLAN §2.4 the safety net calls for …
    ✅ // Debug NOT derived — URL carries DB credentials

## 2. Changelog в коде — ❌
История изменений принадлежит VCS, а не исходнику. Часть формулировок
двусмысленна, поэтому это ориентир, а не жёсткое правило — смотри по контексту.

    ❌ /// # Optional (with defaults) — unchanged
    ❌ /// … since FEAT-0018 … no longer reads DATABASE_URL
    ❌ //! RED→GREEN coverage for Config::load()
    ✅ /// Loads config from the environment; fails fast if DATABASE_URL is unset

## 3. Пересказ очевидного — ❌
Комментарий повторяет то, что уже сказано соседней строкой.

    ❌ // increment counter
       n += 1
    ✅ (без комментария — код самоочевиден)

У этого класса нет надёжного машинного признака — нужно смысловое сопоставление
с соседней строкой. Поэтому его ловят чтением кода — это правило и ревьюер, а не
формальный паттерн.

## Allowlist — никогда не смелл
- `TODO(...)` / `FIXME` / `XXX` с содержанием (в т.ч. голый тикет-реф внутри `TODO`)
- инварианты под `// SAFETY:` / `# SAFETY:`
- security-рационал (`// no Debug — credential URL`)
- неочевидные инварианты и рационал алгоритма

## Как это обеспечивается (два слоя)
1. **Этот референс** + врезки в `01-style-guide.md` и `00-principles.md`
   (Принцип 13) — источник правды: агент держит правило в контексте, пока пишет.
2. **`sdlc:code-reviewer`** — чек-пункт «comment hygiene» ловит то, что
   просочилось (severity minor), читая реальный дифф с окружающим кодом.
