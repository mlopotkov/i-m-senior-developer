# Spec Delta

## ADDED Requirements

### Requirement: Документация называет ограничение Claude Code на файлы отчётов

Документация `/planner:plan-do` MUST сообщать, что Claude Code может добавлять субагенту инструкцию не записывать Markdown-отчёты даже при явно выданном пути. Из-за этого роль может не вызвать `Write`, оставив обязательный файл пустым. Корневой и плагинный README SHALL ссылаться на [баг Claude Code](https://github.com/anthropics/claude-code/issues/101519), различать отказ роли до вызова `Write` и отдельный отказ самого инструмента для некоторых имён файлов и не представлять доступность инструмента либо корректное имя файла как гарантию записи. Это описание внешнего ограничения, а не изменение работы команды.

#### Scenario: Роль завершилась без записи отчёта
- **WHEN** субагент вернул сводку, но не вызвал `Write` для выданного пути и файл остался пустым
- **THEN** документация позволяет опознать известное ограничение хоста по ссылке на баг, а пустой файл не считается завершённым отчётом

#### Scenario: Пользователь применяет наблюдённый обход
- **WHEN** пользователь запускает новый процесс Claude Code с недокументированной `CLAUDE_CODE_REMOVE_PROMPT_STRINGS`, чтобы удалить точное системное примечание
- **THEN** документация описывает это только как наблюдение пользователя, не как поддерживаемую настройку проекта, гарантию поведения или способ отменить отдельную проверку имён инструментом `Write`

#### Scenario: Инструмент отклонил запись из-за имени файла
- **WHEN** субагент вызвал `Write` и получил отказ для имени, подпадающего под другую проверку хоста
- **THEN** документация не выдаёт этот инструментальный отказ за решение модели не вызывать `Write` и не утверждает, что удаление примечания снимет инструментальный запрет
